#### 🖼️ Filtros de Imagem BMP (Filter Less, CS50)
_C_
- Manipulando cada pixel, o programa aplica filtros em imagens BMP da memória
- Filtro Preto e Branco: calcula a média dos valores de cada pixel, arredondando para o mais próximo
- Filtro Sepia: aplica a fórmula que altera os valores dos tons vermelho, verde e azul
- Filtro Reflexão: inverte a imagem horizontalmente, trocando cada pixel com o seu correspondente no outro oposto da imagem
- Filtro Borrão: calcula a média dos pixels em uma grade 3x3 ao redor do pixel original, respeitando os limites da imagem

enviar aquivos do PC para repo
1. criar repositorio vazio no github, depois tudo no terminal do pc
2. inicia repo local
```bash
git init
```
3. adiciona os arquivos e commita
```bash
git add .
git commit -m "primeiro commit"
```
4. define a branch principal como 'main'
```bash
git branch -M main
```
5. conecta o PC ao GitHub (Cole a URL aqui)
```bash
git remote add origin https://github.com/usuario/projeto.git
```
6. envia os arquivos
```bash
git push -u origin main
```
